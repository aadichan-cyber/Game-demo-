# Echoes Below

You are a bat. It is pitch black. **The cave only exists when you hear it.**

Each echolocation ping sends a sound ring outward. As it washes over the cave,
walls and stalactites light up, then fade from memory over a couple of seconds.
Pinging drains your voice; eating glowing moths gives it back. The cave narrows
and speeds up the deeper you go.

## Play

Open `index.html` in any modern browser. It's a single file with no dependencies
and no build step, and it works on desktop and mobile.

| Action | Mouse | Keyboard | Touch |
| --- | --- | --- | --- |
| Fly | move cursor | WASD / arrows | drag anywhere |
| Echolocate | click | Space | tap |
| Pause / mute | | P / M | |

Tips:
- The echo comes back in stereo, so listen for the pan. A sharp high *tick* means a spike.
- Echoes travel at a finite speed: distant walls light up *later* than near ones.
- Moths glow faintly and light up the rock around them. Follow them.
